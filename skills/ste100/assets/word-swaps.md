# Common word swaps

Replacements in the spirit of ASD-STE100. Prefer the word on the right.

**This is not the ASD dictionary.** The specification ships a controlled
dictionary of approximately 900 approved words and approximately 1,200
unapproved words with suggested alternatives. That dictionary is the property of
ASD. Get it from <https://www.asd-ste100.org/>. The table below is a small set of
illustrative swaps drawn from published examples. Use it as a habit-former, not
as an authority.

When a word is not in this table, apply the rule instead: choose the simplest
word that keeps the meaning exact, and use that same word every time.

## Constructions

| Instead of | Write |
|---|---|
| No leaks permitted. | Make sure that there are no leaks. |
| The temperature must be adjusted. | Adjust the temperature. |
| The screws should be replaced. | Replace the screws. |
| It is recommended that you restart. | Restart the service. |
| Care should be taken. | Be careful. |
| The file will be created by the script. | The script creates the file. |
| Installation of the driver is required. | Install the driver. |
| as necessary, as required, if applicable | state the exact condition |

## Words to delete
