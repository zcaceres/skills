# travel-photo-stamp

Transform each uploaded travel photo into an individual Rubber Stamp Travel
Field Notes Poster while preserving the photo faithfully.

## Install

```bash
npx skills add zcaceres/skills -s travel-photo-stamp
```

Add `-g` for global installation, or `-a <agent>` to target a specific agent.

## Usage

Invoke `/travel-photo-stamp` with one or more photos and provide, for each
photo, its verified English location name, record number, three keywords, and
Gregorian year. The skill produces one separate 4:3 poster per photo.
